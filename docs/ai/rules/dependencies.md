# Rules: Dependencies (R-DEP)

Baseline đã được duyệt và lý do của từng package: [`docs/audits/dependency-deep-audit.md`](../../audits/dependency-deep-audit.md).

| ID      | Mức    | Quy tắc                                                                                                                                                                                                                                      | Lý do                                      | Kiểm chứng                 |
| ------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ | -------------------------- |
| R-DEP-1 | MUST   | Trước khi thêm package, kiểm tra theo thứ tự: code có sẵn trong repo → API native (React, Next.js, Web Platform, `Intl`, `fetch`, `<dialog>`) → dependency đã cài → vài dòng code. Chỉ thêm package mới khi cả bốn đều không đủ.             | Mỗi package là chi phí bảo trì và bảo mật. | `review`                   |
| R-DEP-2 | MUST   | Không thêm state management (Zustand, Redux…) khi chưa có state client thật sự dùng chung giữa nhiều nhánh UI. State cục bộ dùng `useState`; filter/phân trang dùng URL; dữ liệu server dùng Server Component.                               | Trường hợp hiện có đều không cần.          | `review`                   |
| R-DEP-3 | MUST   | Không thêm Axios hay HTTP client khác: dùng `httpRequest`/`backendRequest` (`src/lib/api/`). Không thêm thư viện UI thứ hai. Không thêm TanStack Query khi chưa có nhu cầu đọc dữ liệu phía client (polling, infinite scroll, autocomplete). | Trùng chức năng đã có.                     | `review`                   |
| R-DEP-4 | MUST   | Mỗi package mới phải ghi rõ trong mô tả thay đổi: nhu cầu, phương án đã loại, tương thích peer dependency (`pnpm peers check`), ảnh hưởng bundle (đo, không đoán).                                                                           | Quyết định có thể kiểm tra lại.            | `human`                    |
| R-DEP-5 | MUST   | Chỉ dùng pnpm (version trong `packageManager`). Mọi thay đổi dependency đi kèm `pnpm-lock.yaml`; CI cài bằng `--frozen-lockfile`.                                                                                                            | Build tái lập được.                        | `ci`                       |
| R-DEP-6 | MUST   | Không nâng major (Next.js, React, TypeScript, ESLint…) trong cùng thay đổi với tính năng. Không dùng `pnpm.overrides` khi chưa phân tích tương thích.                                                                                        | Major upgrade là một dự án riêng.          | `review`, `human`          |
| R-DEP-7 | SHOULD | Sau khi đổi dependency: `pnpm audit --prod` sạch, `pnpm peers check` không lỗi.                                                                                                                                                              | Giữ runtime không có lỗ hổng đã biết.      | `ci` (`pnpm audit --prod`) |
