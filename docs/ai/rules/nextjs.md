# Rules: Next.js (R-NX)

Áp dụng cho `src/app/**` và mọi component render trong route. Version thật là **Next.js 16.4** (App Router, `cacheComponents`, `partialPrefetching`).

**Trước khi dùng một API Next.js nào, đọc hướng dẫn tương ứng trong `node_modules/next/dist/docs/`**: API của version này khác với kiến thức cũ (ví dụ `next lint` đã bị bỏ, `middleware` đổi thành `proxy`, `params`/`searchParams` là Promise).

Cột **Kiểm chứng**: `tsc` / `lint` / `test` / `e2e` / `build` = tự động; `review` = agent hoặc reviewer kiểm tra; `human` = quyết định của người.

| ID      | Mức    | Quy tắc                                                                                                                                                                                                                                                                              | Lý do                                                                                                                    | Kiểm chứng                                |
| ------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------- |
| R-NX-1  | MUST   | `src/app/` chỉ chứa routing: `page`, `layout`, `error`, `not-found`, `loading`, `route`, metadata. Component tái sử dụng nằm ở `src/components/`; code nghiệp vụ ở `src/features/`.                                                                                                  | Route là nơi ghép, không phải nơi chứa logic.                                                                            | `review`                                  |
| R-NX-2  | MUST   | Mặc định là Server Component. Chỉ thêm `'use client'` khi file dùng state, effect, event handler hoặc browser API. Đặt `'use client'` ở **lá** tương tác, không ở page/layout.                                                                                                       | Giảm JS gửi xuống client; giữ được streaming và PPR.                                                                     | `review`                                  |
| R-NX-3  | MUST   | Client Component không import module `server-only` (`@/lib/env`, `@/lib/auth`, `@/lib/api/backend`, `services/*`). Code chạy được ở cả hai phía không có `'use client'` và không import `server-only`.                                                                               | Chặn lộ secret vào bundle trình duyệt.                                                                                   | `build` (server-only throw)               |
| R-NX-4  | MUST   | Props truyền từ Server sang Client Component phải serialize được: truyền element (`icon={<Plus />}`), không truyền component hay function (trừ Server Action).                                                                                                                       | RSC chỉ serialize được dữ liệu thuần.                                                                                    | `build`, `review`                         |
| R-NX-5  | MUST   | Đọc dữ liệu động (repository, `cookies()`, `searchParams`, session) bên trong `<Suspense>`. Trang không có request-time API thì gọi `await connection()` **trước** khi đọc dữ liệu và session.                                                                                       | Với Cache Components, dữ liệu ngoài Suspense hoặc đọc trước request-time API sẽ bị prerender vào static shell lúc build. | `build` (route phải là `◐`/`ƒ`), `review` |
| R-NX-6  | MUST   | Không thêm `'use cache'`, `cacheLife`, `cacheTag` khi chưa có lý do đo được. Khi thêm: không đưa dữ liệu theo user hoặc secret vào cache key; mutation phải `updateTag`/`revalidateTag` tương ứng.                                                                                   | Cache sai = rò dữ liệu giữa các user hoặc dữ liệu cũ.                                                                    | `review`, `human`                         |
| R-NX-7  | MUST   | Mutation đi qua Server Action trong `src/features/<f>/actions.ts`, sau đó `revalidatePath` (hoặc tag) cho các route bị ảnh hưởng.                                                                                                                                                    | Một đường ghi duy nhất, dễ bảo vệ.                                                                                       | `test`                                    |
| R-NX-8  | MUST   | Mỗi màn hình dữ liệu có: trạng thái loading (Suspense fallback/skeleton), empty state, error state (`error.tsx` hoặc lỗi inline từ `ActionResult`).                                                                                                                                  | Không màn hình nào "trắng" khi chậm, rỗng hay lỗi.                                                                       | `e2e`, `review`                           |
| R-NX-9  | MUST   | Dùng API của framework: Metadata API cho title/description, `next/link` cho điều hướng nội bộ, `redirects()` trong `next.config.ts` cho redirect tĩnh, `next/font` cho font. Không dùng API experimental (`unauthorized()`, `forbidden()`, `authInterrupts`) khi chưa có quyết định. | Ổn định qua các lần nâng version.                                                                                        | `review`                                  |
| R-NX-10 | MUST   | Server Action là endpoint POST công khai: tuân thủ R-SEC-1…R-SEC-4.                                                                                                                                                                                                                  | Ẩn nút trên UI không bảo vệ được gì.                                                                                     | `test`                                    |
| R-NX-11 | SHOULD | Fetch song song bằng `Promise.all` khi các nguồn dữ liệu độc lập.                                                                                                                                                                                                                    | Tránh waterfall.                                                                                                         | `review`                                  |
| R-NX-12 | SHOULD | Filter, search, phân trang lưu trên URL (`searchParams`), không lưu trong global state.                                                                                                                                                                                              | Chia sẻ link được; server render đúng.                                                                                   | `review`                                  |
| R-NX-13 | MAY    | Thêm `loading.tsx` khi muốn fallback cho cả segment; mặc định dùng Suspense trong page để static shell hiển thị ngay.                                                                                                                                                                | Cả hai đều hợp lệ.                                                                                                       | `human`                                   |

Giải thích chi tiết và sơ đồ: [`docs/architecture.md`](../../architecture.md) mục 5–6.
